# MeshForge

**工业 STEP 模型轻量化处理工具**

MeshForge 是一个面向数字孪生、动画演示、可视化展示等场景的 STEP 机械模型轻量化处理工具。通过智能网格简化与视觉保真优化，将复杂的工业 CAD 模型转换为轻量级的 glTF/GLB 格式，在保证视觉效果的前提下大幅降低模型文件大小。

## 项目背景

在数字孪生、虚拟展示、动画演示等应用场景中，直接使用原始 CAD 模型面临以下挑战：

- **文件体积庞大**：复杂装配体可达数百 MB 甚至 GB 级别
- **几何细节过剩**：高精度 CAD 模型包含大量对视觉展示无意义的微小特征
- **加载性能差**：Web 端和移动端难以实时加载和渲染
- **格式不兼容**：STEP 等工业格式无法直接用于 WebGL、游戏引擎等

MeshForge 通过几何分析、特征识别、智能简化等技术路线，将工业级 STEP 模型转换为适合实时渲染的轻量级 glTF 模型，**在保持视觉外观的前提下，实现 10-100 倍的体积压缩**。

## 主要功能

### STEP 导入与解析
- 基于 OpenCASCADE STEPCAFControl_Reader，完整保留装配层级结构
- 自动检测实例化几何体，避免重复存储
- 支持产品结构、颜色、名称等元数据提取

### 几何分析
- **曲面分类**：自动识别平面、圆柱、圆锥、球面、圆环等解析曲面
- **特征识别**：检测孔、倒角、圆角、凸台等制造特征
- **参数提取**：提取半径、轴向、角度等几何参数

### 自适应三角化
针对不同曲面类型采用差异化策略：
- **平面**：稀疏采样，支持四边形网格
- **回转面**：根据曲率和可视角度自适应分段
- **自由曲面**：基于线性/角度偏差的自适应网格
- 所有法向量从 BRep 曲面精确计算，保证光滑 shading

### 智能网格简化
两种简化模式：
1. **按比例简化**：指定目标三角形数量比例 (1% ~ 100%)
2. **按目标文件大小**：指定目标导出文件大小 (MB)，自动反推简化比例

技术特点：
- 基于视觉保真的误差控制
- 特征边界保护（避免孔、倒角等特征变形）
- 多遍渐进式简化
- Sloppy 简化兜底策略

### LOD 生成
- 多级细节层次自动生成
- 基于屏幕像素或距离的 LOD 选择
- 空间聚类 LOD：远距离时自动合并多个对象

### 导出格式
- **glTF 2.0 / GLB**：支持 Draco 几何压缩、GPU Instancing
- **STL**：二进制格式，兼容各类切片软件

## 构建

### 环境要求

- macOS 14+ (Apple Silicon)
- CMake ≥ 3.25
- C++20 编译器 (Clang)
- Homebrew 依赖

### 安装依赖

```bash
brew install opencascade sdl2 glm spdlog nlohmann-json eigen tbb draco
```

### 编译

```bash
git clone https://github.com/Xintong-Wg/MeshForge.git
cd MeshForge
mkdir build && cd build
cmake ..
cmake --build .
```

可执行文件：`build/bin/MeshForgeApp`

## 使用说明

### 基本工作流

1. **导入 STEP**：`File → Open STEP...` 或 `Cmd+O`
2. **查看场景**：在 Scene Tree 中浏览装配层级，支持多选 (Ctrl/Cmd+Click)
3. **简化模型**：在 Simplify Settings 面板中设置参数并应用
4. **导出结果**：`File → Export glTF...` 或 `File → Export STL...`

### 简化设置

| 参数 | 说明 |
|------|------|
| **By Ratio** | 按三角形比例简化，0.1 表示保留 10% 的三角形 |
| **By Target File Size** | 按目标文件大小简化，自动计算最优比例 |
| **Target Error** | 视觉误差阈值，控制简化质量 |
| **Preserve Boundary** | 保护网格边界（CAD 闭合物体通常不需要） |

### 视口交互

| 操作 | 行为 |
|------|------|
| 中键拖拽 | 轨道旋转 |
| Shift + 中键拖拽 | 平移 |
| 滚轮 | 缩放 |
| Focus 按钮 | 聚焦到模型中心 |

## 技术架构

### 核心模块

| 模块 | 路径 | 功能 |
|------|------|------|
| STEP 读取 | `src/Geometry/STEPReader.cpp` | XCAF 遍历、实例检测、变换提取 |
| 几何分析 | `src/Geometry/BRepAnalyzer.cpp` | 曲面分类、特征识别 |
| 自适应三角化 | `src/Geometry/AdaptiveTessellator.cpp` | 分类型三角化策略 |
| 特征处理 | `src/Geometry/DefeatureProcessor.cpp` | 小特征去除 |
| 网格简化 | `src/Mesh/Simplifier.cpp` | meshoptimizer 简化、LOD 生成 |
| 场景图 | `src/Scene/SceneGraph.cpp` | 层级管理、视锥剔除 |
| glTF 导出 | `src/IO/glTFExporter.cpp` | glTF/GLB 序列化、Draco 压缩 |
| UI | `src/UI/UIManager.mm` | ImGui 界面、交互逻辑 |

### 关键数据结构

```cpp
// 网格数据
struct MeshData {
    std::vector<Vertex> vertices;  // 顶点：位置、法向量、UV、切线
    std::vector<Index>  indices;   // 三角形索引
    AABB aabb;                     // 包围盒
};

// 简化参数
struct SimplifyParams {
    SimplifyMode mode;             // Ratio | TargetFileSizeMB
    float targetRatio;             // 目标三角形比例
    float targetFileSizeMB;        // 目标文件大小
    float targetError;             // 视觉误差阈值
    bool preserveBoundary;         // 保护边界
};

// 曲面分类标签
enum class SurfaceType {
    Plane, Cylinder, Cone, Sphere, Torus, BSpline, Other
};
```
